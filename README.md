# kawai-metube ✨ (◕‿◕) ♡

A sleek, responsive YouTube clone web application built with **React 19, TypeScript, Tailwind CSS, and Lucide React** featuring an authentic **Red & Blue Kawaii theme** and a **Multi-Engine Video Player**!

---

## 🌟 Key Features

### 🎬 Multi-Engine Video Player (100% Playable)
- **🌸 Kawaii Anime Synth Engine**: Built-in 60FPS dynamic animated canvas with animated anime mascot cat, retro cyber horizon grid, real-time reactive audio equalizer bars, and an interactive Web Audio chill synthesizer creating soothing lofi beats.
- **🔴 YouTube Stream**: Official embedded YouTube playback with verified channels.
- **🎥 Direct HTML5 Stream**: HTML5 video with automatic fallback recovery.
- **Custom Player Controls**: Scrubber timeline, volume slider, playback speed, theater mode, and full-screen toggle.

### 💖 Kawaii Red & Blue Theme
- **Vibrant YouTube Aesthetic**: High-energy Crimson Red (`#ff0033` / `#ff0055`) + Cyber Cyan Electric Blue (`#00f0ff`) over obsidian night dark background.
- **Heart Reactions**: Floating heart reactions (`♡`) for video likes and comment likes.
- **Cute Channel Avatars**: Dual red-to-blue gradient rings and glowing live badges.
- **Interactive Comment Section**: Real-time comments with quick emoji reaction bar.

### 🧭 Navigation & Views
- **Feed / Category Pills Bar**: `All ✨`, `Gaming 🎮`, `Music 🎵`, `Anime & Kawaii 🌸`, `Tech 💻`, `Coding ⚡`, `Lofi Cafe ☕`, `AI 🤖`, `Live 🔴`.
- **Responsive Sidebar**: Collapsible desktop sidebar, mini-rail view, and slide-in drawer on Watch page.
- **Full Library System**: Liked Videos playlist hero view, Watch History with clear history, Watch Later, and Creator Studio.
- **Instant Search & Voice Search**: Filter videos by keyword, tags, or voice simulation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/wraithcode0/kawai-metube.git
cd kawai-metube

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
